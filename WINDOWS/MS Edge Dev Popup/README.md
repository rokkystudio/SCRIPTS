# MS Edge Dev Popup

`Disable-EdgeDevModeWarning.bat` отключает предупреждение Microsoft Edge о режиме разработчика на один год. Скрипт закрывает все процессы `msedge.exe`, создаёт резервную копию каждого изменяемого файла `Preferences` и обновляет значение `dev_mode_warning_snooze_end_time`.

## Запуск

Закройте Edge вручную, если в нём есть несохранённые данные, затем запустите `Disable-EdgeDevModeWarning.bat` двойным щелчком или из командной строки. Скрипт дополнительно принудительно завершает все процессы Edge:

```bat
taskkill /F /IM msedge.exe
```

После сообщения об успехе откройте Edge и проверьте, что диалог больше не появляется.

## Профили и резервные копии

Скрипт не ограничивается профилем `Default`: он находит все папки профилей в `%LOCALAPPDATA%\Microsoft\Edge\User Data`, если в них есть файл `Preferences`. Так поддерживаются, в частности, `Profile 1`, `Profile 2` и другие созданные профили. Служебный `System Profile` пропускается.

Рядом с каждым обработанным файлом появится копия вида:

```text
Preferences.backup-YYYYMMDD-HHMMSS
```

Чтобы вернуть исходное состояние, закройте Edge и замените `Preferences` нужной резервной копией.

Текущий путь профиля можно посмотреть на странице [`edge://version`](edge://version): найдите поле **Путь профиля**. Файл для изменения находится в этой папке и называется `Preferences`.

## Как выбирается время

Edge хранит это значение в микросекундах от 1 января 1601 года (UTC). Скрипт вычисляет корректное значение на один год вперёд при каждом запуске, вместо числа `99999999999000000`, которое может оказаться за пределами допустимого диапазона для Edge.
